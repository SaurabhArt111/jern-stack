# JERN Stack — Frontend Showcase

**JERN = JSON • Express • React • Node**

Created & founded by **Saurabh Surendra Maurya**.

This project is intentionally **frontend-only**. It is a visual/interactive website that explains the JERN architecture and its recommended project structure.

## Pages / sections
- Hero / JERN identity
- Interactive JERN Gallery
- The principle behind JERN
- Project Structure
- Use cases
- Philosophy / creator section

## Project structure explained

```text
jern-stack-boilerplate/
├── backend/
│   ├── data/
│   │   └── data.json       # Your local "Database"
│   ├── server.js           # Express Server & REST API
│   └── package.json
└── frontend/               # React Application (Vite-powered)
    ├── src/
    └── package.json
```

## Run

```bash
npm install
npm run dev
```

No backend is required for this showcase.

## Design
Premium editorial / experimental developer aesthetic, responsive, normal CSS, no Tailwind.
